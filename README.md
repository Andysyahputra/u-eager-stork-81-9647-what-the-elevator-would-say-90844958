An entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-what-the-elevator-would-say-90844958) "What the Elevator Would Say" bounty. `main.ts` (Node 22, standard library only) writes one line — the funniest thing a talking elevator could say — to `/output/entry.txt`:

> Going down? I have carried 14 people, 3 dogs and one very loud argument today. Please hold the doors — and the drama.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
